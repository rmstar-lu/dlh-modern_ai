
# Tree models

## `0-build.py`

A function to create a decision tree classifier using Scikit-learn.

## `1-train.py`

A function to train a tree-based classifier.

## `2-draw.py`

A function to display the textual structure of a trained decision tree classifier.

## `3-generate_predictions.py`

A function to generate predictions from a trained tree-based classifier.

## `4-evaluate.py`

A function that generates a detailed classification report.

## `5-pre_pruning.py`

A function to perform a Grid Search for the best pre-pruning hyperparameters.
